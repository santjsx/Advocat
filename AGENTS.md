# Project Rules & Guidelines (Karpathy / Advocat)

## 1. Think Before Coding
- State assumptions explicitly. If uncertain or if multiple interpretations exist, ask before implementing.
- Push back if a simpler approach exists.

## 2. Simplicity First
- Minimum code that solves the problem. Nothing speculative.
- No single-use abstractions or unwanted flexibility.

## 3. Surgical Changes
- Touch only what is strictly necessary to fulfill the request.
- Match existing code styles.
- Clean up only your own orphans.

## 4. Goal-Driven Execution
- Define verifiable success criteria and ensure code compiles with 0 errors (`npx tsc --noEmit`).
